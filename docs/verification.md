처음 테스트 명령은 저장소 외부에서 실행해 import 오류가 났다. 저장소 루트에서 재실행해 통과했다. README에 실행 위치를 명시했다. 슬라이드 첫 로드에서 기본 계산값 표시가 비어 있어 정적 기본값을 넣었다.

## 실행하지 않은 범위

- LoRA/QLoRA의 학습·벤치마크·GPU 성능 재현.
- 논문의 모든 표와 부록에 대한 정독·재검증.
- Deep Research, Google Scholar 자동 탐색, 체계적 문헌고찰.
- 실제 옵시디언 앱에서의 설치/UI 시험. Markdown 파일과 관계도 출력까지만 확인.
- 특정 에이전트 제품의 세션 훅 등록·실제 이벤트 실행.

실제 확인한 것은 공개 논문의 제한된 방법 범위로 입력→근거 기록→계산→선택 출력→화면 검토가 연결된다는 점이다. 다른 분야의 논문과 모든 에이전트에서의 품질을 보장하지 않는다.
