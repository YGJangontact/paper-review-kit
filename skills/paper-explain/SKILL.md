# 논문 이해와 시각적 설명

[공통 근거 기록](../paper-review/references/evidence-contract.md)과 [설명 원칙](../paper-review/references/explanation.md)을 읽는다.

먼저 접근한 범위와 독자 수준을 기록한다. 원문이 없으면 제목으로 방법을 만들어내지 않고, 확보한 초록/자료의 범위로 답한다. 핵심 질문에 필요한 배경만 설명한다.

문제와 기준 방법을 작은 사례로 소개한 뒤 새 방법이 바꾸는 부분을 보여준다. 아키텍처 그림은 상자·화살표의 의미, 텐서 크기, 학습/추론 차이를 설명한다. 이름만 나열하는 구조 설명은 피한다.

핵심 식은 원문 번호·가정·기호·차원을 연결한다. 작은 계산 예와 시각화는 설명용임을 밝히고 원문 결과와 구분한다. 수치 검증을 실행하면 입력·코드·결과를 남긴다. 실행하지 않았다면 손계산 또는 미실행 예시로 표기한다.

그래프의 축·척도·오차 범위, 표의 지표 방향과 평가 조건을 설명한다. 도식은 개념을 돕지만 실험 증거가 아니다. 기술적으로 틀린 비유는 제거한다.

결과는 사용자의 질문에 맞는 직관·동작·심화 해설과 이해 확인이다. 장황한 배경 사전이나 반복 요약을 붙이지 않는다. 성능 타당성의 본격 검토가 필요하면 evidence-check를 읽는다.
