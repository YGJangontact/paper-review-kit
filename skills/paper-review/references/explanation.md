# 초보자 설명 기준

문제의 구체적 장면 → 기존 방법이 막히는 이유 → 핵심 변화 → 실제 동작 순으로 설명한다. 필요한 배경만 먼저 보충하고 용어를 처음 쓸 때 역할을 풀이한다. 독자가 전문가여도 처음 접하는 세부 분야는 설명할 수 있다.

직관·원리·수학/구현으로 깊이를 나눈다. 한 개의 작은 예제를 이어서 사용하고, 단순화한 조건을 밝힌다. 비유가 맞지 않는 지점을 짚는다. ‘쉽다’고 선언하거나 핵심 가정을 지우지 않는다.

수식은 목적, 기호·차원·단위, 입력/출력, 계산 순서, 작은 수치 예, 변화 예측, 원문의 가정을 연결한다. 모호한 기호를 임의로 확정하지 않는다. 수식이 핵심이 아니면 계산을 강제하지 않는다.

시각화는 도식/정적 그래프/상호작용 중 질문에 맞게 선택한다. 축·단위·범례와 설명용/실측 구분을 넣는다. 원문 수식과 수치 예를 대조하고 가능한 경우 경계값·차원·정규화 등을 확인한다. 정규화 가중치를 곧바로 인과적 설명이라고 부르지 않는다. 정적 그림으로 충분하면 대시보드를 만들지 않는다.

학습 목적이면 이해 확인 질문 1~3개와 답의 근거를 넣을 수 있다. 요약만 요청한 경우 퀴즈를 강제하지 않는다. ‘이해됐나요?’ 대신 예제 결과를 설명하거나 조건 변화의 영향을 예측하게 한다.
