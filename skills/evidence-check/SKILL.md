# 연구 주장과 실험 근거 검토

[공통 근거 기록](../paper-review/references/evidence-contract.md)을 읽는다.

핵심 주장부터 한 문장씩 나누고 절·식·표·그림 위치에 대응한다. 접근 범위 밖이면 미확인으로 두고 필요한 자료를 기록한다. ‘근거 없음’과 ‘틀림’을 혼동하지 않는다.

주장에 관련된 조건을 선택해 확인한다: 데이터/평가 단위, 분할·누수, 전처리, 비교 모델 설정, 학습 예산·연산량, 지표, 반복 횟수·불확실성, 외부 검증. 의료영상에서는 이미지 단위와 환자 단위 분할을 특히 구분하되 모든 논문에 임상 체크리스트를 강제하지 않는다.

Ablation은 제거/변경한 요소 이외 조건이 같은지 확인한다. 통제되지 않은 비교를 인과적 효과라고 표현하지 않는다. 서로 다른 데이터·지표의 수치로 순위를 만들지 않는다. 평균만으로 모든 사례의 개선을 주장하지 않는다.

결론은 ‘원문에서 보고’, ‘이 범위에서 뒷받침’, ‘조건부 해석’, ‘미확인’, ‘원문과 불일치’를 구분한다. 재현 실행 없이 재현 검증 완료라고 하지 않는다. 자료 형식·링크 검사기는 내용의 참거짓을 보증하지 않는다.

검토 결과는 중요 주장, 근거 위치, 조건, 판단, 다음 확인 사항으로 간결하게 남긴다. 근거보다 확신을 높이는 표현을 수정한다.
